# Sudha Rani Maddala — AI Training Portfolio

This is the React/TypeScript portfolio built from the **yujisatojr/react-portfolio-template** selected by Sudha.

## Where to edit content

Most personal content is now centralised in:

`src/content.ts`

Edit that file to change:
- email, GitHub, LinkedIn and website
- training areas
- workshop descriptions
- projects
- experience/history

For the homepage wording, edit:

`src/components/Main.tsx`

For colours, spacing and visual styling, edit:

`src/assets/styles/*.scss`

## Run locally

Install Node.js, then from the project directory:

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Build for production

```bash
npm run build
```

## Deploy

Recommended: GitHub + Vercel. You can also use GitHub Pages, Netlify or another static hosting provider.

### Custom domain

Once deployed, buy a domain such as `sudhatrains.ai`, `sudhaai.io` or a suitable `.com` and connect it to the hosting provider. The domain and hosting are separate from the React code, so the site can be updated without changing the domain.

## Positioning

This version is deliberately positioned as a **corporate AI training/facilitator portfolio**, not a generic job-seeker portfolio. It can be expanded later with individual workshop pages, sample slides, testimonials, training videos and booking links.
